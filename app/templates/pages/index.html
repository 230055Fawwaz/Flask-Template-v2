Python Flask Modern Monolith

Template boilerplate siap pakai berbasis Flask dengan pola Application Factory, arsitektur Service Layer, database SQLAlchemy 2.0, serta interaktivitas dinamis berbasis HTMX dan Alpine.js tanpa build-step Node.js.

Uji Coba Demo HTMX Pelajari Arsitektur

Pola Arsitektur & Prinsip Desain v2

Struktur modular, teruji, dan memisahkan tanggung jawab (Separation of Concerns)

📦

1. Model (Data)

app/models/

Mendefinisikan skema tabel database dan relasi entitas menggunakan Flask-SQLAlchemy modern.

  • Terisolasi dari manipulasi HTTP
  • Mendukung migrasi Alembic (Flask-Migrate)
  • Dilengkapi serialisasi to_dict()
⚙️

2. Service Layer (Logika)

app/services/

Memproses transaksi database, query db.select(), dan aturan bisnis tanpa tercampur kode HTTP.

  • Menggantikan Controller tradisional
  • Penanganan rollback otomatis saat galat
  • Dapat digunakan ulang oleh API maupun Web
🔌

3. Factory & Routes

app/routes/ & app/__init__.py

Fungsi create_app() menginisialisasi aplikasi. Blueprint HTTP memetakan request dan merespons partial HTML / JSON.

  • Ekstensi di extensions.py cegah circular import
  • Dukungan header HX-Request cerdas
  • Konfigurasi terpisah Dev, Testing, dan Prod
🎨

4. Modern Monolith UI

app/templates/ & static/

Merender UI responsif dengan Jinja2 + HTMX + Alpine.js yang tersimpan 100% lokal dan offline.

  • Zero reload SPA-like experience dengan HTMX
  • Auto-dismiss notifikasi & state dengan Alpine.js
  • Tanpa npm, webpack, maupun build tools rumit

Otomasi Perintah Cross-Platform (Invoke & Ruff)

Gunakan file tasks.py untuk produktivitas tinggi di Windows, Linux, dan macOS

invoke run

Menjalankan Flask development server dengan auto-reload di http://127.0.0.1:5000/.

invoke format

Memformat kode dan merapikan urutan import secara instan menggunakan linter modern ultra cepat Ruff.

invoke test

Mengeksekusi automated test suite lengkap berbasis Pytest dengan database SQLite in-memory.
