Langkah Memulai Proyek Baru

Struktur modular siap pakai: ikuti 4 langkah ini untuk menambahkan fitur baru

📦

1. Buat Model Data

app/models/

Definisikan skema tabel database dan relasi entitas Anda menggunakan Flask-SQLAlchemy modern.

  • Buat berkas model baru (misal: user_model.py)
  • Ekspor model di app/models/__init__.py
  • Jalankan migrasi skema database
⚙️

2. Tulis Service Layer

app/services/

Letakkan query db.select(), validasi data, dan aturan bisnis aplikasi di kelas Service.

  • Isolasi aturan bisnis dari HTTP controller
  • Gunakan db.session.commit() dan rollback otomatis
  • Dapat dipakai ulang oleh Web maupun API
🔌

3. Daftarkan Rute

app/routes/

Petakan permintaan HTTP ke metode Service dan kembalikan response partial HTML atau JSON.

  • Tambahkan rute di main_routes.py atau blueprint baru
  • Dukung header HX-Request untuk respons instan
  • Gunakan flash message untuk status pengguna
🎨

4. Rancang UI Dinamis

app/templates/

Buat template tampilan dengan Jinja2 + HTMX + Alpine.js yang 100% lokal dan offline.

  • Warisi layout utama dari layouts/base.html
  • Gunakan atribut hx-get, hx-post, dll.
  • Gaya siap pakai dengan CSS variables & dark theme
