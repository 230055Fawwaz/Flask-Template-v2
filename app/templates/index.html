Python Flask MVC Template

Template proyek web tangguh berbasis Flask dengan pola Application Factory, Blueprint Routes, pencegahan Circular Import, serta struktur Model-View-Controller (MVC) yang rapi dan modular.

Pola Arsitektur & Prinsip Desain

Setiap layer dipisahkan berdasarkan tanggung jawab tunggal (Single Responsibility Principle)

📦

1. Model (Data)

app/models/

Mendefinisikan skema tabel database dan representasi entitas menggunakan Flask-SQLAlchemy.

  • Terisolasi dari logika HTTP
  • Mendukung migrasi otomatis (Alembic)
  • Dilengkapi method serialisasi to_dict()
🎨

2. View (Tampilan)

app/templates/ & static/

Merender antarmuka pengguna interaktif menggunakan HTML5 semantik, Vanilla CSS, dan Vanilla JS.

  • Desain modern & responsif tanpa framework CSS berat
  • Sistem layout Jinja2 inheritance (base template)
  • Komponen alert dan modal interaktif
⚙️

3. Controller (Logika)

app/controllers/

Memproses validasi, manipulasi database, dan alur bisnis. Menghindari penulisan query langsung di file routes.

  • Satu file controller per domain fitur
  • Error handling dan proteksi rollback database
  • Dapat digunakan ulang oleh web & REST API
🔌

4. App Factory & Routes

app/__init__.py & routes/

Fungsi create_app() mengonfigurasi aplikasi. Blueprint memetakan URL HTTP murni ke fungsi Controller.

  • Ekstensi di extensions.py mencegah circular import
  • Kemudahan pengujian unit (TestingConfig)
  • Struktur modular untuk penambahan blueprint baru

Otomasi Skrip Batch (.bat)

Tersedia skrip siap pakai untuk mempermudah alur kerja di sistem operasi Windows

run_server.bat

Mengaktifkan virtual environment secara otomatis dan menjalankan development server Flask di localhost:5000.

setup_env.bat

Membuat virtual environment Python .venv baru dan menginstal semua paket dari requirements.txt.

db_migrate.bat

Menu praktis untuk menjalankan inisialisasi database, membuat migrasi skema baru, dan mengeksekusi upgrade migrasi.
